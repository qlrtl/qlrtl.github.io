# vixy rivera · academic site

Personal academic website, served by GitHub Pages.

- `index.html` — the whole page (content and styling live here)
- `cv.pdf` — the CV linked from the page; replace it with a newer file of the same name to update
- `images/portrait.jpg` — profile photo
- `images/favicon.svg` — browser-tab icon

To edit: open `index.html` on GitHub, click the pencil icon, change the text, and commit. The site updates within a minute or two.
